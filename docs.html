Installation

To initialize the project, ensure you have the core framework dependencies linked in your HTML head. This documentation assumes you are using Tailwind CSS for styling.

<script src="https://cdn.tailwindcss.com"></script>

Configuration

Modify the config.json file located in your root directory to update site-wide branding. The hydration script will automatically pull these values into the UI.

Repository Card

The repository cards are generated dynamically using the fetchFeaturedRepos() function. Ensure your repository name exists in the config.json list exactly as it appears on GitHub.
